INSTALLATION & USAGE
────────────────────

STEP 1: INSTALL SERVICE (First Time Only)
   Run as Administrator:
   powershell -ExecutionPolicy Bypass -File .\install-karanremote.ps1
   
   Result:
   • Files copied to C:\Program Files\karanRemote\
   • Windows service created and started
   • Auto-start configured for PC boot
   • Service now running silently

STEP 2: GET DEVICE ID (First Time Only)
   Run this command:
   & 'C:\Program Files\karanRemote\karanRemote.exe'
   
   Result:
   • Window appears with your Device ID
   • Write down the ID (looks like: 123456789)
   • Close the window when done

STEP 3: DONE!
   The service now:
   • Runs silently in background
   • Starts automatically at PC boot
   • Accepts connections with password "karan"
   • Shows no UI, tray, or notifications

CONNECT FROM REMOTE DEVICE:
   1. Open karanRemote/RustDesk on another computer
   2. Enter Device ID: (the number you wrote down)
   3. Enter Password: karan
   4. Click Connect
   5. Instant access granted!
